# robot-assembly

One-page site for Novara's CAD-to-assembly work. Static (GitHub Pages, deploy from `main`), all paths relative.

- `index.html`, `styles.css`, `script.js`: the page
- `assets/`: hero video (placeholder cut from the factory run), poster, logo, favicons
- `replay/`: interactive three.js replay of the recorded MuJoCo run, loaded on click
